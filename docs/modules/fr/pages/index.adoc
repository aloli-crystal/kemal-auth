= Kemal Auth

Bibliotheque d'authentification pour les applications web https://kemalcr.com/[Kemal] en Crystal.

== Modules

[cols="1,3"]
|===
| Module | Description

| `KemalAuth::Password`
| Hachage et validation BCrypt des mots de passe avec regles conformes CNIL (12+ caracteres, majuscule, minuscule, chiffre, caractere special)

| `KemalAuth::Token`
| Generation et verification de tokens JWT

| `KemalAuth::Session`
| Gestion des sessions via cookies HTTP (Kemal)

| `KemalAuth::SmtpConfig`
| Configuration du serveur SMTP

| `KemalAuth::PasswordReset`
| Recuperation de mot de passe par courriel

| `KemalAuth::UserManager`
| Gestion des utilisateurs et invitations
|===
