= Kemal Auth

Authentication library for https://kemalcr.com/[Kemal] web applications in Crystal.

== Modules

[cols="1,3"]
|===
| Module | Description

| `KemalAuth::Password`
| BCrypt password hashing and validation with CNIL-compliant rules (12+ chars, uppercase, lowercase, digit, special char)

| `KemalAuth::Token`
| JWT token generation and verification

| `KemalAuth::Session`
| Session management via HTTP cookies (Kemal)

| `KemalAuth::SmtpConfig`
| Configurable SMTP server settings

| `KemalAuth::PasswordReset`
| Password recovery via email

| `KemalAuth::UserManager`
| User management and invitations
|===
